## 🚀 Inside My Project Lab

### 🌐 01 | TechNova — Who Gets Access?

**The challenge:** How do you stop everyone on a company network from accessing everything?

🔧 Built a simulated organisational network in Cisco Packet Tracer, working with segmentation, routing, and Access Control Lists.

**🎯 The lesson:** Security isn't just about connecting systems. It's about controlling access.

### 🤖 02 | Meridian Financial Services — When AI Becomes a Risk

**The scenario:** An employee pastes confidential client information into an unapproved AI tool. What could go wrong? 👀

🔍 I'm investigating the threats, vulnerabilities, potential impacts, and security controls through a structured cybersecurity risk assessment.

**🎯 The lesson I'm exploring:** Sometimes the biggest security vulnerability isn't the technology. It's how people use it.

🚧 **Status:** Investigation in progress.
